CSC 301 – Question 2: Solving Problems Using Recursion

Project Title
Implementation of Recursive Algorithms in C++

Project Description
This project demonstrates the use of recursion to solve four programming problems using C++

Functions Implemented
1.	Factorial Calculation: Calculates the factorial of a non-negative integer using recursion.
2.	Fibonacci Sequence: Generates the Fibonacci sequence recursively.
3.	String Reversal: Reverses a given string using a recursive function.
4.	Binary Search: Searches for a target value in a sorted array using recursive binary search
5.	
Testing
Each recursive function was tested with different inputs, including edge cases
The tests include:
•	Factorial of 0, 1 and 5.
•	Fibonacci sequences with 1, 6 and 0 terms.
•	String reversal using HELLO, A, DATA and an empty string.
•	Binary search for existing and non-existing values, including an empty array

Programming Language
C++

Source Code
The complete source code is available in main.cpp

Compilation and Execution
Compile using:
g++ main.cpp -o main

Run using:
./main

Conclusion
The project demonstrates how recursion can be applied to solve mathematical, string-processing and searching problems in C++.
